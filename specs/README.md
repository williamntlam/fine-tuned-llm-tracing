# Feature specifications

Each implementation feature has a folder named
`<number>-<feature-name>`, such as `001-incident-generator`.

Copy `000-feature-name/` to create a new specification, replace its example
values, and then follow the workflow in [`docs/specs.md`](../docs/specs.md).
The `000` folder is a template, not an implementation specification.

Every feature folder contains `spec.md`, `spec.yaml`, and `artifacts.md`.
Read `artifacts.md` first for the concise review brief; use `spec.md` for the
full rationale and `spec.yaml` for structured metadata.
